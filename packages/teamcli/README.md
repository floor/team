# teamcli

This is the same tool as [team](https://github.com/floor/teamcli), under its other name. npm refuses the bare package name as too similar to another package's, so the package is `@teamcli/cli`.

```sh
npm install -g @teamcli/cli
```

The command is `team`. `teamcli` is the same command.

Repository: https://github.com/floor/teamcli
